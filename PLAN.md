# План: «LimeCraft» — минималистичный лаунчер Minecraft

> **Статус:** рабочий каркас на **Rust + eframe/egui**. Ранняя версия плана
> предполагала Electron; от него отказались, и этот файл описывает актуальную
> реализацию. Что готово, а что нет — в таблице раздела 6.

## 1. Идея

Лаунчер Minecraft в стиле минимализм, в светло-зелёно-жёлтых тонах. Он умеет:

- ставить vanilla-версии из официального манифеста Mojang (релизы, по желанию снапшоты);
- ставить версии с загрузчиком: Fabric, Quilt, Forge, NeoForge;
- искать и устанавливать модпаки (`.mrpack`) и отдельные моды с Modrinth;
- запускать игру в офлайн-режиме (ник + детерминированный UUID).

## 2. Технологический стек

- **Rust 2024**, UI — **eframe/egui 0.37** (нативное окно, без браузерного рантайма).
- Сеть — `reqwest` (blocking, `rustls`), тяжёлая работа идёт в фоновых потоках.
- Архивы — `zip`, хэши — `sha1`/`sha2`, офлайн-UUID — `md-5`.
- Данные лежат в пользовательской папке (`dirs::data_dir()/LimeCraft`).

## 3. Архитектура

```
src/
├─ main.rs        точка входа, иконка окна, panic-хук
├─ app.rs         весь UI: вкладки «Сборки», «Моды», «Другое», диалоги
├─ theme.rs       палитра и настройка egui
├─ assets.rs      загрузка встроенных PNG в текстуры
└─ core/          логика без зависимости от UI
   ├─ mojang.rs   манифест, модель version.json, правила, слияние inheritsFrom
   ├─ modrinth.rs поиск, версии, поиск по хэшам, разбор и распаковка .mrpack
   ├─ mods.rs     моды/ресурспаки/шейдеры: список, `.disabled`, обновления, план зависимостей
   ├─ install.rs  установка vanilla/загрузчиков/модпаков/модов, прогресс, отмена
   ├─ download.rs загрузка с таймаутами, ретраями, SHA-1, отменой
   ├─ launch.rs   выбор Java, classpath, аргументы, запуск процесса
   ├─ instance.rs инстансы, состояние (атомарная запись), безопасные пути
   └─ account.rs  аккаунт, офлайн-UUID
```

Раскладка инстанса: `instances/<имя>/mines/{libraries,versions,assets,mods,...}`.

## 4. Как это работает

- **Vanilla:** манифест → `version.json` (сохраняется как есть) → клиент, библиотеки, ассеты (параллельно, с проверкой SHA-1).
- **Fabric/Quilt:** ставится vanilla-основа, затем профиль загрузчика из meta API. При запуске профиль сливается с родителем (`inheritsFrom`).
- **Forge/NeoForge:** скачивается installer и запускается как `java -jar … --installClient`, чтобы выполнились его процессоры.
- **Модпаки:** `.mrpack` распаковывается безопасно, файлы качаются с проверкой хэшей, учитываются `env` и `overrides`/`client-overrides`.
- **Содержимое:** установленные файлы опознаются по SHA-1 (`/version_files`), обновления ищутся через `/version_files/update`, выключение — переименование в `.disabled` (как в Prism и Modrinth App).
- **Запуск:** Java подбирается по `javaVersion`, classpath строится по списку библиотек, аргументы разбираются с правилами и плейсхолдерами, вывод пишется в `launcher.log`.

## 6. Состояние реализации

| Область | Состояние |
|---|---|
| Vanilla: установка и запуск | Готово, проверено на уровне тестов ядра |
| Fabric / Quilt | Готово, не проверено живым запуском |
| Forge / NeoForge | Через installer; не проверено |
| Модпаки `.mrpack` | Готово: проверка хэшей, `env`, защита путей |
| Моды, ресурспаки, шейдеры (Modrinth) | Готово: поиск с фильтром совместимости, установка с зависимостями, список установленных, включение/выключение, удаление, обновления по хэшам |
| Отмена установки, таймауты, ретраи | Готово |
| Офлайн-аккаунт (ник) | Готово: несколько профилей с аватарами, ник для сборки; входа Microsoft нет (решено не делать) |
| Кастомизация (по итогам опроса) | Готово: акцент, тема, фон, масштаб и шрифт, вид библиотеки и группы, иконка и цвет сборки, окно игры, действие после запуска, пресеты памяти, живая консоль |
| Радужный акцент, цвет текста по фону | Готово: акцент плавно меняет оттенок; яркость картинки измеряется при выборе, тема и цвет текста подбираются сами |
| Скины для офлайна | Готово: библиотека, предпросмотр, по нику, копия в `CustomSkinLoader/LocalSkin`. Без мода CustomSkinLoader в игре скин не виден (ограничение офлайн-режима) |
| Пиксельный стиль | Готово: палитра, «клавиши», карточки-обложки, верхняя навигация, Manrope; «Мягкий» стиль сохранён как вариант |
| Анимации и песок | Готово: переходы страниц, плавные кнопки и вкладки, карточки по очереди, поворот фигурки скина, песок при прокрутке настроек; выключатели в настройках |
| Набор значков | Готово: Phosphor (шрифт), единое выравнивание по видимой части глифа |
| Импорт сборок | Готово: из папки, из `.mrpack` и Prism / MultiMC `.zip`, из Prism, PolyMC, CurseForge, Modrinth App, `.minecraft`. Не поддержано: архивы CurseForge (нужен ключ API), ATLauncher, MultiMC без экспорта |
| Иконки Modrinth | Готово: каталог, модпаки, установленные файлы; кэш миниатюр; сборка из модпака получает его иконку |
| Проверка сети, зеркала, понятные ошибки поиска | Готово |
| Тесты интерфейса без окна | Готово (`cargo test --release`, поддельные серверы) |
| Проверка скачиваемого | SHA-1/SHA-256/SHA-512 для всего, что скачивается (см. README) |
| Автоскачивание JRE | Готово (Adoptium, проверка SHA-256) |
| Настройки сборки (RAM, JVM, Java) | Готово (вкладка «Настройки» страницы сборки), там же иконка, цвет плитки, группа и ник |
| Старые версии (≤1.12, LWJGL 2) | Natives распаковываются, живым запуском не проверено |

## 7. API

- Mojang: `piston-meta.mojang.com` (манифест и `version.json`), `resources.download.minecraft.net` (ассеты).
- Modrinth v2 (без ключей): `/search`, `/project/{id}`, `/project/{id}/version`; в `.mrpack` — `modrinth.index.json`.
- Fabric: `meta.fabricmc.net/v2`, Quilt: `meta.quiltmc.org/v3`.
- Forge: `files.minecraftforge.net` (promotions) и `maven.minecraftforge.net`.
- NeoForge: `maven.neoforged.net`.
