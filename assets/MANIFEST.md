# Манифест ассетов LimeCraft

Таблица готовых ассетов в `assets/`: где используется и примечания.
Список может дополняться при расширении UI (см. [ASSET_PROMPT.md](../ASSET_PROMPT.md)).

| Файл | Где используется | Примечание |
|---|---|---|
| `badge-256.jpg` | Лого-бейдж в шапке окна | Загружается в `src/assets.rs` (поле `badge`); квадратный 256×256. |
| `hero-1920x1080.jpg` | Фон главного экрана (и загрузки) | Широкоформатный 1920×1080, нежный светло-зелёный градиент с «пустым» центром под UI. |
| `play-256.jpg` | Иконка кнопки «Играть» | Жёлто-зелёный play-треугольник в скруглённом квадрате; поле `play_icon` в `assets.rs`. |
| `empty-state.png` | Иконка пустого состояния (нет модов/сборок) | Прозрачный PNG; поле `empty_state` в `assets.rs`. |
| `modpack-256.png` | Иконка разделов сборок (Modrinth) | Стек из трёх скруглённых блоков; поле `modpack_icon` в `assets.rs`. |
| `favicon-64.ico` | Иконка окна (и системный значок) | Фавиконка-листик 64×64; используется вне egui-текстур. |
| `Gemini_Generated_Image_92vdaq92vdaq92vd.jpg` | Запасной вариант главного (replace-фон) | Резервная картинка «героя» на случай проблем с основным фоном. |

## Правила добавления

- Имена файлов — `kebab-case`, без пробелов и кириллицы.
- Иконки — прозрачный PNG/ICO 256×256 (или кратно), фоны — 1920×1080.
- Только цвета из палитры LimeCraft (см. [README](../README.md)).

> Полные требования к стилю генерации и вариантам — в
> [ASSET_PROMPT.md](../ASSET_PROMPT.md).
