# LimeCraft — лаунчер для Minecraft

**LimeCraft** — это программа, через которую можно запускать Minecraft.
В ней можно выбрать версию игры, поставить моды и сборки и сменить скин.
Всё делается кнопками, ничего настраивать вручную не нужно.

Версия **1.0.0**. Что нового, смотрите в [CHANGELOG.md](CHANGELOG.md).

---

## 🟢 Как установить (Windows)

1. Откройте страницу **[Releases](https://github.com/tinsundew-lgtm/sundew-launcher/releases)**
   (справа на странице репозитория).
2. Скачайте файл `LimeCraft-1.0.0-windows-x64.zip`.
3. Нажмите на него правой кнопкой мыши и выберите **«Извлечь всё»**.
4. Откройте получившуюся папку и дважды щёлкните **`LimeCraft-1.0.0.exe`**.

Готово! Если Windows покажет синее окно «Система Windows защитила ваш компьютер»,
нажмите **«Подробнее»**, а потом **«Выполнить в любом случае»**.

## 🐧 Как установить (Linux Mint / Ubuntu)

1. На странице **[Releases](https://github.com/tinsundew-lgtm/sundew-launcher/releases)**
   скачайте файл `LimeCraft-1.0.0-linux-x86_64.tar.gz`.
2. Нажмите на него правой кнопкой и выберите **«Распаковать здесь»**.
3. Откройте папку, нажмите в ней правой кнопкой → **«Открыть в терминале»** и введите:

   ```bash
   ./install.sh
   ```

4. LimeCraft появится в меню программ, в разделе **«Игры»**.

Подробнее про Linux: [packaging/linux/README-LINUX.md](packaging/linux/README-LINUX.md).

## 🎮 Как начать играть

1. **Придумайте ник.** Откройте **«Настройки» → «Профили (ники)»** и впишите имя игрока:
   от 3 до 16 символов, только английские буквы, цифры и `_`.
2. **Создайте сборку.** Нажмите **«Новая сборка»** и выберите версию игры.
   Сборка — это отдельный Minecraft со своими модами и мирами.
   Их может быть сколько угодно.
3. **Нажмите «Играть».** В первый раз лаунчер скачает игру. Это займёт
   несколько минут, полоска покажет, сколько осталось.

Java ставить не нужно: лаунчер скачает её сам.

## 🧩 Моды, ресурспаки и шейдеры

Перейдите во вкладку **«Каталог»** вверху окна. Найдите мод через поиск и нажмите
**«Установить»**. Всё, что уже стоит в сборке, видно на странице сборки во вкладке
**«Содержимое»**. Лаунчер сам покажет только подходящие моды и докачает те, без
которых мод не работает. Всё берётся с сайта [Modrinth](https://modrinth.com).

> Чтобы ставить моды, при создании сборки выберите **загрузчик модов**: Fabric,
> Quilt, Forge или NeoForge. Если не знаете, что выбрать, берите **Fabric**.

## 👕 Скины

Во вкладке **«Скины»** можно загрузить картинку скина с компьютера или найти скин
по нику игрока. Чтобы скин был виден в игре, в сборку нужен мод
**CustomSkinLoader**. Лаунчер сам подскажет, если его нет.

## 📦 Перенести сборку из другого лаунчера

**«Новая сборка» → «Импорт».** LimeCraft сам находит сборки из Prism Launcher, PolyMC,
CurseForge, Modrinth App и обычного Minecraft. Ещё можно выбрать папку с игрой или
файл `.mrpack`. Ваши старые файлы не меняются: лаунчер делает копию.

## 🎨 Оформление

**«Настройки» → «Оформление»:** тёмная или светлая тема, цвет, своя картинка на фоне,
размер интерфейса. Если анимации мешают, их можно выключить там же.

## ❓ Если что-то не работает

| Что случилось | Что сделать |
|---|---|
| Не пускает на сервер | Вход здесь только по нику, без аккаунта Microsoft. Такой ник пускают на серверы, где выключена проверка лицензии, а также в одиночную игру и по локальной сети (LAN). |
| Ничего не скачивается | **«Настройки» → «Проверить сеть»**. Лаунчер покажет, какой сайт недоступен, и сам попробует запасные серверы. |
| Игра вылетает | Откройте сборку → вкладка **«Журнал»**. Там написано, что пошло не так. |
| Хочу удалить игру | Сборки и настройки лежат в папке `LimeCraft` в папке пользователя. Удалите её. |

## 🛠 Для разработчиков

Лаунчер написан на **Rust** с интерфейсом на **eframe/egui**. Нужен
[Rust](https://rustup.rs/), стабильная версия.

```bash
cargo run --release
```

```bash
cargo test --release
```

- **Windows:** можно просто дважды щёлкнуть `start.cmd`.
- **Linux:** `./packaging/linux/build-linux.sh` поставит нужные пакеты, соберёт
  программу и положит её в `dist/` (эта папка в git не попадает).
- **Выпуск:** готовые файлы для Windows и Linux собирает GitHub Actions
  (`.github/workflows/release.yml`). Его можно запустить вручную во вкладке **Actions**
  или отправить тег вида `v1.0.0`. Тогда файлы сами появятся в Releases.

Код устроен так: `src/core/` — скачивание, установка и запуск игры (без интерфейса),
`src/app/`, `src/ui.rs`, `src/theme.rs` — окно и кнопки, `assets/` — картинки и шрифты,
которые встраиваются в программу.
