# LimeCraft — лаунчер для Minecraft

**Версия 1.1.4.** Лёгкий лаунчер на Rust с интерфейсом egui/eframe: отдельные сборки Minecraft, моды и модпаки Modrinth, локальные скины, капсулы восстановления и галерея скриншотов.

Изменения версий: [CHANGELOG.md](<CHANGELOG.md>).

## Установка Windows

1. Откройте [GitHub Releases](https://github.com/tinsundew-lgtm/sundew-launcher/releases).
2. Скачайте `LimeCraft-1.1.4-setup-x64.exe` и проверьте источник файла/контрольную сумму.
3. Выберите папку приложения. Самописный установщик Rust + egui работает для текущего пользователя, без прав администратора, Inno Setup, NSIS и WebView.
4. Проверьте **папку данных**: установщик ищет существующие сборки и настройки в стандартном расположении, portable-папках рядом с приложением/установщиком и в `LIMECRAFT_HOME`. Если данные найдены, первая подходящая папка выбирается автоматически; при нескольких вариантах выберите нужную. Можно указать другую существующую папку вручную.
5. Установите и запустите лаунчер. Сборки, конфиги, миры и скриншоты не копируются и не перезаписываются установщиком: рядом с exe сохраняется указатель `limecraft-data.json`.

Если данные находятся в нестандартном месте, выберите корень **данных лаунчера** с `launcher_state.json` и/или `instances`, а не отдельную папку `mods`. Сборка из другого лаунчера переносится через импорт.

Для запуска без установки можно скачать `LimeCraft-launcher-windows-x64.exe` или ZIP Windows. По умолчанию данные — `%APPDATA%/LimeCraft`. Portable-папка `LimeCraft-data` рядом с exe также распознаётся. Переменная `LIMECRAFT_HOME` имеет приоритет над указателем установщика. Если явно выбранная папка недоступна, лаунчер сообщает об ошибке, а не переключается незаметно на пустую.

Установщик пока не создаёт ярлыки и не регистрирует автоматический деинсталлятор. Для удаления закройте лаунчер и удалите его exe, квитанцию `limecraft-install.json` и указатель `limecraft-data.json` из папки приложения. Игровые данные удаляйте только отдельно и осознанно. Выпуск не подписан Authenticode; не отключайте защиту Windows и запускайте только файлы из доверенного релиза.

## Автообновление Windows

При запуске лаунчер проверяет **стабильный** последний релиз этого репозитория. Черновики и prerelease не устанавливаются. Проверку можно повторить в настройках.

При наличии новой версии:

1. Нажмите «Скачать обновление лаунчера»; загрузка идёт с прогрессом и отменой.
2. Проверяется размер и SHA256 файла.
3. Остановите игру и завершите фоновые операции, затем подтвердите «Установить обновление и перезапустить».
4. Нативный helper ждёт закрытия лаунчера, сохраняет старый exe и заменяет его. Папка данных остаётся прежней.

Для замены нужны права записи в папку приложения. Если осталась `.limecraft-update` после ошибки, сначала проверьте `update-error.txt` и резервный `previous.exe`; не удаляйте резервную копию вслепую. SHA256 защищает от повреждения загрузки, **не от компрометации аккаунта GitHub/релиза**. Цифровой подписи обновлений пока нет. Автоустановка доступна только на Windows x64; Linux обновляется вручную. Версии до 1.1.4 ещё не умеют обновляться этим способом — сначала установите 1.1.4 вручную.

## Как начать играть

- В настройках создайте профиль с ником (3–16 латинских букв, цифр или `_`). Вход офлайн, без авторизации Microsoft; серверы с обязательной проверкой аккаунта такой вход не принимают.
- Создайте сборку, выберите Minecraft и при необходимости Fabric, Quilt, Forge или NeoForge.
- Нажмите «Играть». Подходящую Java лаунчер может скачать автоматически, если свой путь не задан.

## Моды и модпаки

Каталог использует **Modrinth**. Поиск, категории, карточки проектов, версии, зависимости, избранное и корзина помогают устанавливать содержимое в выбранную сборку. CurseForge как дополнительный каталог не подключён.

Установленное содержимое видно в сборке → «Содержимое». Вместо галочек используются переключатели включения/отключения (`.disabled`). Общая полоса установки модов, модпаков и CustomSkinLoader видна на любой странице. Прогресс файлов текущего проекта может начинаться заново при переходе к следующему проекту в пакете.

## Скины

На вкладке «Скины» добавьте PNG или скачайте скин по нику. Для локального скина в игре нужен **CustomSkinLoader**. Есть кнопки установки в выбранную сборку или во все совместимые сборки; версия подбирается по Minecraft и загрузчику. Vanilla пропускается, загрузчик не меняется скрытно. Старые/неизвестные версии мода не гарантированно совместимы.

## Капсулы, диагностика и заметки

- **Капсулы:** снимок модов, конфигов, ресурспаков, шейдеров, versions и настроек запуска. Миры — только по отдельной галочке. Есть сравнение и восстановление с подтверждением, проверкой SHA256 и обязательной страховочной копией.
- **Диагностика:** известные сигнатуры журналов, фрагменты ошибок, изменения относительно последней капсулы, проверка JAR и повторяющихся Fabric mod id. Это рекомендации, а не доказательство виновности конкретного мода или автоматическое исправление.
- **Сессия:** ручные заметки «на чём остановился», следующая цель и прикреплённое локальное изображение. Подбор сборки по времени и функция «Друзья» удалены в 1.1.4.

Капсулы — полные локальные копии без автоочистки: контролируйте место. Ссылки на изображения в заметках не копируют оригиналы. Подробнее: [CAPSULES.md](<CAPSULES.md>).

## Скриншоты сборки

Откройте сборку → **«Скриншоты»**. Галерея показывает изображения из её `mines/screenshots`:

- сделайте снимок F2 в Minecraft и нажмите «Обновить скриншоты»;
- выберите имя файла для предпросмотра;
- откройте оригинал или папку снимков.

Поддерживаются PNG, JPG/JPEG и WebP. Скриншоты не отправляются в сеть и не удаляются галереей.

## Импорт и оформление

«Новая сборка» → «Импорт»: перенос из найденных папок других лаунчеров или поддерживаемых архивов. Источник остаётся на месте. Наличие папки CurseForge для импорта не означает поддержку его онлайн-каталога.

В настройках доступны темы, акцент, фон, масштаб и отключение анимаций. При проблемах со скачиванием используйте проверку сети, при вылетах — журнал сборки и диагностику.

## Linux

Скачайте Linux-архив из релиза, если он опубликован, распакуйте и запустите `./install.sh`. Инструкции: [README-LINUX.md](<packaging/linux/README-LINUX.md>). Нативный графический установщик и автоматическая замена exe описывают только Windows.

## Разработка

Нужен стабильный [Rust](https://rustup.rs/). Интерфейс — eframe/egui, игровые операции выполняются на фоновых потоках.

```bash
cargo run --release
cargo test
```

Windows: [start.cmd](<start.cmd>) / [start.ps1](<start.ps1>) используют установленный WinLibs при Rust GNU. LLVM-MinGW без libgcc для этого toolchain не подходит. После очистки `target` первая сборка заметно дольше.

Сборка установщика из корня:

```powershell
.\packaging\native-installer\build-installer.ps1
```

Политика PowerShell может запрещать неподписанные скрипты: не меняйте системную политику вслепую, используйте доверенную среду сборки или команды Cargo из [документации установщика](<packaging/native-installer/README.md>).

### Публикация и автообновления

[GitHub Actions release](<.github/workflows/release.yml>) собирает Windows/Linux при push тега `v*` или ручном запуске. Перед тегом синхронизируйте версии обоих Cargo-проектов, lockfile и changelog, выполните тесты.

Для v1.1.4 после проверки/коммита:

```bash
git push origin main
git tag v1.1.4
git push origin v1.1.4
```

В стабильном GitHub Release должны быть **точно** эти файлы для автообновления:

- `LimeCraft-launcher-windows-x64.exe` — сам лаунчер, не установщик;
- `LimeCraft-launcher-windows-x64.exe.sha256` — ASCII SHA256 (первое слово — 64 шестнадцатеричных символа).

Actions готовит и прикладывает их вместе с установщиком и ZIP. Самого тега недостаточно: пользователям обновление доступно после публикации стабильного релиза с обоими assets. Ручной запуск Actions без тега сохраняет artifacts, но не публикует релиз автоматически. Доступность GitHub, ограничения API и права записи могут помешать обновлению; остаётся ручная установка.
