# Журнал изменений

## 1.0.0

Первый стабильный выпуск.

### Что есть

- **Игра:** установка vanilla, Fabric, Quilt, Forge и NeoForge; запуск с проверкой всех
  скачанных файлов; автоматическая установка Java (Adoptium); живой журнал игры.
- **Каталог Modrinth:** моды, ресурспаки, шейдеры и модпаки с иконками, установка
  с зависимостями, список установленного с обновлениями, зеркала при блокировке сервера.
- **Импорт сборок:** из папки, из `.mrpack` и экспорта Prism / MultiMC, а также
  из Prism, PolyMC, CurseForge, Modrinth App и `.minecraft`.
- **Офлайн-профили** с несколькими никами, аватарами и своим ником для сборки.
  Входа через Microsoft нет.
- **Скины для офлайна:** библиотека, предпросмотр спереди и сзади, загрузка из файла
  или по нику, копия в папку мода CustomSkinLoader при запуске.
- **Анимации:** страницы плавно появляются, а карточки и блоки настроек выходят по
  очереди; карточки сборок и скинов приподнимаются под курсором; зелёный индикатор
  скользит от вкладки к вкладке; кнопки приподнимаются, а при нажатии по ним идёт волна;
  уведомления выезжают снизу; фигурка скина покачивается и поворачивается; при выборе
  скина летят искры; шкалы загрузки идут плавно.
  При прокрутке настроек страница рассыпается: край, через который уходит содержимое,
  разваливается на пиксельные блоки, с него срываются песчинки и разлетаются по ветру.
  Пока страница стоит (в том числе упёрлась в край), эффекта нет. Всё отключается в «Настройки → Оформление».
- **Оформление:** пиксельный и мягкий стиль, тёмная / светлая / системная тема, цвет
  акцента и «Радуга», фон-картинка с автоподбором цвета текста, масштаб, шрифт
  (встроенный Manrope), вид библиотеки, группы, свои иконки и цвета сборок.

- **Значок:** пиксельная иконка лаунчера в окне, на панели задач, в шапке и в самом
  `LimeCraft.exe` (с версией в свойствах файла).

### Исправлено перед выпуском

- **Игра не запускалась с Sodium: «Failed to locate library: lwjgl.dll».**
  Для Minecraft 26.x Mojang указывает natives LWJGL и для x64, и для arm64 под одним
  правилом `windows`; лаунчер подключал оба, и LWJGL видел только arm64. Теперь
  библиотеки чужого процессора не попадают ни в classpath, ни в распаковку.
- **Системная папка Temp недоступна для записи** (на некоторых компьютерах):
  игра и установщики Forge / NeoForge получают свою папку `tmp` внутри сборки,
  а библиотеки LWJGL лежат в `natives` и указаны через `org.lwjgl.librarypath`.
- Если нужной natives-библиотеки нет на диске, лаунчер говорит об этом сразу
  («переустановите сборку»), а не оставляет игру падать.

### Linux

- Подготовлена сборка для Linux Mint / Ubuntu (папка `packaging/linux`, GitHub Actions в
  `.github/workflows/release.yml`): установка в меню одной командой, автоскачивание Java
  (Adoptium, `.tar.gz`, с проверкой SHA-256), поиск Prism / PolyMC / Modrinth App в Linux-папках.
  Готовый Linux-бинарник собирается на GitHub или на самом Mint (см. `README-LINUX.md`).

### Известные ограничения

- Сборки CurseForge (`.zip` с `manifest.json`) не импортируются: для их модов нужен
  ключ CurseForge API.
- В офлайне ванильный Minecraft не показывает чужие скины; нужен мод CustomSkinLoader.
- Forge и NeoForge проверены на уровне установки, живой запуск — выборочно.
