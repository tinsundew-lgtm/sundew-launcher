# Журнал изменений

## 1.1.0 — Капсулы, сессии и нативный установщик

- **Капсулы сборок:** локальные копии модов, конфигов и настроек запуска, сравнение SHA256, восстановление с подтверждением и страховочной копией. Миры включаются отдельно.
- **Диагностика:** рекомендации по журналам, фрагменты ошибок, сравнение с последней капсулой, проверка JAR и дублирующих Fabric mod id.
- **Общий прогресс:** установка/обновление модов и модпаков видны на любой странице; включение модов — анимированными переключателями.
- **CustomSkinLoader:** явная установка в выбранную или все совместимые сборки, с проверкой версии игры и загрузчика. Vanilla пропускается.
- **Друзья (первый этап):** код состава модов, сравнение версий/хэшей/активности, установка недостающих файлов с Modrinth с предварительной капсулой. Онлайн-комнаты и сервер готовности пока отсутствуют.
- **Сессия:** заметки, следующая цель, локальный скриншот и параметры продолжительности; подбор сборок на главной по заданному времени и настроению.
- **Самописный установщик Rust + egui:** встроенный launcher.exe, выбор папки, проверка SHA256, безопасная замена предыдущего exe. Без Inno Setup/NSIS/WebView; пока без ярлыков и автоматического деинсталлятора.
- Подробные ограничения и правила работы описаны в CAPSULES.md и packaging/native-installer/README.md.

## 1.0.3 — Карточка проекта+

- **Вкладка «Зависимости»:** что версия требует, рекомендует, содержит внутри и с чем
  несовместима; видно, что уже стоит в сборке. Можно выбрать версию, поставить одну
  зависимость или все недостающие обязательные разом, открыть карточку зависимости.
- **Обновить и удалить из карточки:** у установленного проекта показано, какая версия
  стоит; если для сборки есть новее — кнопка «Обновить до …», а «Удалить из сборки»
  убирает файл.
- **Список изменений:** у версий с описанием появилась кнопка «Изменения», она раскрывает
  текст прямо в списке.
- **Корзина:** тележка у проектов в каталоге и в карточке; вкладка «Корзина» проверяет,
  для каких проектов есть версия под сборку, и ставит все подходящие одной кнопкой (уже
  стоящие проекты обновляются, а не дублируются). Корзина живёт, пока запущен лаунчер.

## 1.0.2 — Каталог 2.0

- **Сортировка:** подходящие, популярные, по подписчикам, новые, обновлённые.
- **Категории:** кнопка «Категории» открывает панель с категориями Modrinth на русском,
  сгруппированными по смыслу (категории, особенности, разрешение, нагрузка на компьютер).
  Выбранные категории показаны над списком, щелчок по ним снимает фильтр. Подходят только
  проекты со всеми выбранными категориями. Категория в карточке проекта открывает каталог
  с этим фильтром.
- **Бесконечная прокрутка:** следующая страница результатов подгружается, когда список
  доходит до конца; над списком видно, сколько всего найдено.
- **«Установлено»:** проекты, которые уже стоят в выбранной сборке, отмечены в каталоге и
  в карточке, а кнопка установки у них неактивна. Модпаки, из которых уже сделана сборка,
  тоже отмечены. В «Версиях» карточки установленная версия помечена, а установка другой
  версии заменяет старый файл — двух копий одного мода в сборке не бывает.
- **Избранное:** звёздочка на карточках каталога, модпаков и в карточке проекта. Новая
  вкладка «Избранное» собирает отмеченные проекты по типам; список хранится вместе с
  настройками лаунчера.
- Модпаки получили те же сортировку, категории, прокрутку и избранное.
- Версии в карточке проекта всегда идут от новых к старым.

## 1.0.1 — Карточка проекта

- **Карточка проекта Modrinth** для модов, ресурспаков, шейдеров и модпаков: шапка со
  статистикой и категориями, описание (Markdown с HTML), версии с фильтрами по версии игры
  и загрузчику, выделением подходящих и установкой конкретной версии, галерея с крупным
  просмотром и стрелками.
- Ссылки («Modrinth», ссылки в описании) открываются в браузере системным обработчиком:
  раньше на части систем Windows они молча не открывались.
- Картинки каталога больше не перестают загружаться после ухода со страницы.
- **Установщик для Windows** (`LimeCraft-<версия>-setup-x64.exe`): мастер на русском и
  английском, ставится без прав администратора (или для всех пользователей), ярлыки в
  «Пуске» и на рабочем столе, обновление поверх старой версии; при удалении спрашивает,
  удалять ли игры и настройки.
- **Новый установщик для Linux** (`install.sh`): проверка системы и библиотек, выбор
  пунктов галочками, обновление с сохранением данных, `-y` для установки без вопросов.
  Программа теперь лежит в `~/.local/lib/limecraft`, удаление — `uninstall.sh` оттуда же.

## 1.0.0

Первый стабильный выпуск.

### Что есть

- **Игра:** установка vanilla, Fabric, Quilt, Forge и NeoForge; запуск с проверкой всех
  скачанных файлов; автоматическая установка Java (Adoptium); живой журнал игры.
- **Каталог Modrinth:** моды, ресурспаки, шейдеры и модпаки с иконками, установка
  с зависимостями, список установленного с обновлениями, зеркала при блокировке сервера.
- **Импорт сборок:** из папки, из `.mrpack` и экспорта Prism / MultiMC, а также
  из Prism, PolyMC, CurseForge, Modrinth App и `.minecraft`.
- **Офлайн-профили** с несколькими никами, аватарами и своим ником для сборки.
  Входа через Microsoft нет.
- **Скины для офлайна:** библиотека, предпросмотр спереди и сзади, загрузка из файла
  или по нику, копия в папку мода CustomSkinLoader при запуске.
- **Анимации:** страницы плавно появляются, а карточки и блоки настроек выходят по
  очереди; карточки сборок и скинов приподнимаются под курсором; зелёный индикатор
  скользит от вкладки к вкладке; кнопки приподнимаются, а при нажатии по ним идёт волна;
  уведомления выезжают снизу; фигурка скина покачивается и поворачивается; при выборе
  скина летят искры; шкалы загрузки идут плавно.
  При прокрутке настроек страница рассыпается: край, через который уходит содержимое,
  разваливается на пиксельные блоки, с него срываются песчинки и разлетаются по ветру.
  Пока страница стоит (в том числе упёрлась в край), эффекта нет. Всё отключается в «Настройки → Оформление».
- **Оформление:** пиксельный и мягкий стиль, тёмная / светлая / системная тема, цвет
  акцента и «Радуга», фон-картинка с автоподбором цвета текста, масштаб, шрифт
  (встроенный Manrope), вид библиотеки, группы, свои иконки и цвета сборок.

- **Значок:** пиксельная иконка лаунчера в окне, на панели задач, в шапке и в самом
  `LimeCraft.exe` (с версией в свойствах файла).

### Исправлено перед выпуском

- **Игра не запускалась с Sodium: «Failed to locate library: lwjgl.dll».**
  Для Minecraft 26.x Mojang указывает natives LWJGL и для x64, и для arm64 под одним
  правилом `windows`; лаунчер подключал оба, и LWJGL видел только arm64. Теперь
  библиотеки чужого процессора не попадают ни в classpath, ни в распаковку.
- **Системная папка Temp недоступна для записи** (на некоторых компьютерах):
  игра и установщики Forge / NeoForge получают свою папку `tmp` внутри сборки,
  а библиотеки LWJGL лежат в `natives` и указаны через `org.lwjgl.librarypath`.
- Если нужной natives-библиотеки нет на диске, лаунчер говорит об этом сразу
  («переустановите сборку»), а не оставляет игру падать.

### Linux

- Подготовлена сборка для Linux Mint / Ubuntu (папка `packaging/linux`, GitHub Actions в
  `.github/workflows/release.yml`): установка в меню одной командой, автоскачивание Java
  (Adoptium, `.tar.gz`, с проверкой SHA-256), поиск Prism / PolyMC / Modrinth App в Linux-папках.
  Готовый Linux-бинарник собирается на GitHub или на самом Mint (см. `README-LINUX.md`).

### Известные ограничения

- Сборки CurseForge (`.zip` с `manifest.json`) не импортируются: для их модов нужен
  ключ CurseForge API.
- В офлайне ванильный Minecraft не показывает чужие скины; нужен мод CustomSkinLoader.
- Forge и NeoForge проверены на уровне установки, живой запуск — выборочно.
