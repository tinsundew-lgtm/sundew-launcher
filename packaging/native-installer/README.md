# LimeCraft Native Setup

Самописный установщик на Rust + eframe/egui. Не использует NSIS, Inno Setup, WiX, WebView, PowerShell для установки или скачивание exe во время установки. PowerShell нужен только разработчику для сборки.

## Сборка из корня проекта

```powershell
.\packaging\native-installer\build-installer.ps1
```

Результат: `dist/native-installer/LimeCraft-Setup.exe`. В него встроен `target/release/limecraft-launcher.exe`. Для выпуска без пересборки лаунчера используйте `-SkipLauncherBuild` (ответственность за актуальность payload на разработчике).

Установщик проверяет SHA256 встроенного payload и записанного exe. Это проверка целостности, **не цифровая подпись**: она не защищает от подмены всего установщика. Выпуск пока не подписан Authenticode.

## Поведение

- Установка по умолчанию в `%LOCALAPPDATA%/Programs/LimeCraft`, без повышения прав.
- Выбор другой папки, фоновая запись, индикатор этапов и запуск после завершения.
- Старый exe заменяется только при наличии собственной квитанции и совпадении её хэша. Неизвестные или вручную изменённые exe не перезаписываются.
- Сначала запись и проверка staging, затем замена. При обычной ошибке замены выполняется возврат старого exe. При аварийном завершении процесса/отключении питания staging может остаться; автоматического восстановления после сбоя питания пока нет.
- Если лаунчер работает и Windows блокирует exe, закройте его и повторите. При остатке `.limecraft-setup-stage` сначала вручную проверьте сохранённые файлы и резервные копии, затем уберите staging.
- Нет рекурсивного удаления пользовательских папок. Игровые данные и миры установщик не трогает.
- Пока нет ярлыков, регистрации в списке программ Windows и автоматического деинсталлятора. Для удаления закройте приложение и удалите только `limecraft-launcher.exe` и `limecraft-install.json` из выбранной папки. Данные `%APPDATA%/LimeCraft` сохраняются; удаление данных — отдельное осознанное действие пользователя.
- Лицензия лаунчера: Apache-2.0, см. корневой LICENSE. Для дистрибуции сохраняйте лицензионные уведомления проекта.

## Разработка и тесты

```powershell
cargo test --manifest-path packaging/native-installer/Cargo.toml --target-dir target
```

В debug без `LIMECRAFT_INSTALLER_PAYLOAD` доступен только просмотр интерфейса; установка отключена. Release без payload не собирается. Тесты устанавливают синтетический payload только во временную тестовую папку.

Rust GNU на Windows требует совместимого GCC/WinLibs. Скрипт использует уже установленный WinLibs, если он обнаружен; LLVM-MinGW без libgcc не подходит для текущего GNU toolchain.
